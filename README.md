# Calculator Web App

A simple calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean and responsive interface.

---

## Features

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Decimal support
* Delete last digit (Del)
* Clear display (C)
* Prevents multiple decimals in a number
* Handles division by zero

---

## Project Structure

calculator/

* index.html
* mystyle.css
* myscript.js
* README.md

---

## Technologies Used

* HTML5
* CSS3 (Grid & Flexbox)
* JavaScript

---

## How It Works

* User clicks buttons to enter numbers and operators
* Input is shown on the display
* When "=" is pressed, calculation is performed
* Result is displayed instantly

---

## How to Run

1. Open the project folder in Visual Studio Code
2. Open `index.html`
3. Right-click → **Open with Live Server** (recommended)
   OR double-click the file to open in browser
